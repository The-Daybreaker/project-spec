# 通用项目模板

这是一套面向人+Agent协作开发的通用项目模板。模板分为两大部分，框架和spec：
框架（冷启动、任务板、agent 记忆、异步交流、git 管理）保证任何项目最低
限度可运转，更加详细的工作流编排由 spec 包声明。

## 写给用户

> 由于现有Agent的能力不足，很多规范写进AGENTS.md也无法保证执行，因此这里写一些面向用户的提醒，由用户来把关。

1. **使用正向提示词**：除非是在给AI设定规范，否则最好不要使用“不要xxx”这样的提示词，因为从现有大模型的表现来看，越是强调不要，模型越会记住，并且会把“不要xxx”直接写进文档内，污染上下文。因此最好采用正向描述，“把xxx改为xxx”、“只需要xxx”。
2. **信息安全**：在项目发布到公开渠道之前，最好让Agent审计一下项目内是否有隐私文件，AI总是会把各种信息写进文档、代码内部，为了防止信息泄露，最好也人工复核一下各个文档。

## 快速开始

1. 手动或者让AI复制本模板到新项目目录（不含 `_trash/`、`.git/`、`__pycache__/`）。
2. 首次对话和 agent 对齐项目背景与目标，按照 `spec/AGENTS.md` 的指引选择并安装合适的spec。
3. 如果没有符合要求的spec，可以从云端拉取模块和构建规则，自己构建合适的spec。

## 目录速览

| 目录           | 放什么                                         |
| ------------ | ------------------------------------------- |
| `spec/`      | spec 包与构建规则按需从云端拉取（指引见 `spec/AGENTS.md`）    |
| `context/`   | 由spec驱动的文档存放区，spec生成的文档默认会存放在这个位置。          |
| `process/`   | runtime：task.md + memory.md + inbox / pending / reviews |
| `workspace/` | 开发主工作区，默认包含两个子目录: source + delivery         |
| `logs/`      | 归档文件夹，存放已经过期的文件                             |

详细协作协议（冷启动链、异步交流、规范）见 `AGENTS.md`。
