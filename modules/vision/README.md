# 愿景与排期（vision）

项目的长期需求总览和排期，都记在 `context/vision.md` 一份文件里：
定位 / 需求正文 / 远期方向 / 演进原则 / 里程碑 / 未排期池，文末附近三期
排期表，滚动更新。vision 是活文档，随时可写。

- **适用**：有长期规划需求的项目。
- **不管**：方案、技术选型。

- **启用**：agent 按 `assets/vision-template.md`（仅参考格式）在 `context/`
  下实例化 `vision.md`，之后负责维护。

给 agent 的规范见 `MODULE.md`，结构化声明见 `module.json`。
