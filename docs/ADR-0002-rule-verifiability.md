# ADR-0002 — 红线与要求可验证性改造（三要素元规范 + 安全门禁 + 测试模块 + 反定型强化 + 需求分层）

> 状态：已接受 | 日期：2026-08-27 | Supersedes：— | Superseded by：—
> 位置说明：本工作区（母项目）无 `private/dev` 登记册，ADR 落于 `docs/`；
> 模板骨架（`project-template/private/dev/adr/`）保持不动。

## 背景（Context）

- PRD-0002 已定稿（2026-08-27，用户确认，含 F8 增补）；RFC-0002 评审通过
  （2026-08-27，D1-D7 全部按推荐）；两轮调研（RESEARCH-0002/0003）支撑。
- 用户经验：对 AI 的要求必须「可展示 + 可验收 + 解释原始意图」，否则 AI 倾向
  不做；红线本身也要可验证（红线 16 与反定型均「无法验证是否被遵守」）。
- 用户确认：可选增强「共识卡推进结论附信心等级/残余风险」不采纳。

## 决策（Decision）

1. **红线 1「要求三要素（意图/展示/验收）」设为最顶层红线**（自指，按三要素写）；
   存量红线 1-17 顺延为 2-18；新增红线 19「敏感信息与私有区边界」；全链引用
   全局 grep 校准（含 ADR-0001「红线 17」→ 18、红线条数 17 → 19）。
2. **存量规范/红线三要素体检**：先出符合性矩阵（模板全部红线 + 精简版规范 +
   工作区自身规范）与缺口清单，修复方式随后由用户定（本轮全修或分批）。
3. **推送前安全门禁三层**：`scan_secrets.py` 进模板 + `pre_release_check.py`
   集成内容级扫描（`--strict`）；`.githooks/pre-push` + `init_project.py` 配置
   `core.hooksPath`；持续集成步骤兜底；冒烟自检注入样例验证钩子拦截。
4. **私有区防外发**：`private/` 禁设远端、禁打包；例外三连（全面个人信息检查 →
   报告 → 用户确认）；发布链/打包断言。
5. **测试模块**：审计验证阶段验证节点拆子阶段（测试设计 → 自测 → 用户验收）；
   测试报告双区（自测区 + 用户验收区，对齐 UAT/IEEE 829 要素）；用例由项目
   自实现、框架自选；模板不预置 `tests/`。
6. **红线 17（原 16）三要素化**：番茄炒蛋/东坡肉原始意图 + diff 影响文件清单
   展示 + 辩护性措辞扫描（独立脚本 `scan_defensive.py`：提交信息/PR 硬拦、
   注释/文档人工复核清单）。
7. **共识卡融合反定型**：硬触发清单（六类节点必须展示）+ 重检行外部化 +
   共识卡固定块 4 项（认知基线/缺口/质疑/推进结论）+ 阶段卡合规两行扩为七项
   （加「红线遵循」）+ `check_dev_docs.py` 锚点断言（📌 共识卡块、4 节非空、
   「重检：」行）。
8. **需求文档分层**：模板新增 `private/dev/ROADMAP.md`（文件名 ROADMAP，标题
   「长期需求与展望（路线图）」，唯一长期入口，正文=当前状态覆盖式更新）；
   版本需求文档头部加「所属版本」「关联路线图条目」字段，只写本版本增量；
   `check_dev_docs.py` 路线图一致性断言；工作区落地 `docs/ROADMAP.md`。
9. **母项目轻量流程**：沿用 ADR-0001 先例——不建 DESIGN 文件，ADR 确认后直接
   进入实现。

## 后果（Consequences）

### 正面

- 规则三要素化：展示面可见、验收面可核对，解决「AI 倾向不做 / 无法验证」；
- 推送前拦截个人信息与凭据（三层互补），CI 不再是最晚防线；
- 测试与用户验收分流明确，测试报告有签署标准；
- 需求阅读负担降低（长期文档 + 本版本文档）。

### 负面

- 红线重编号是全链冲击（文档/技能/矩阵/摘要），需全局校准；
- 新增 `scan_secrets.py` / `scan_defensive.py` / `.githooks` / 路线图骨架，
  模板维护面增大；
- 合规两行增一项、共识卡固定块增加阶段卡篇幅（换取可验证性）。

## 备选方案（Alternatives）与不选原因

1. 辩护性措辞并入 `scan_secrets.py`（RFC D1-B）：职责混杂、降噪互相干扰，不选；
2. 钩子只扫待推送 diff（D2-B）：复杂易漏，不选；
3. 精简版新增规范 19（D3-B）：失去合并意义，不选；
4. 合规独立「红线遵循」区块（D4-B）：增加阶段卡体积，不选；
5. 路线图仅文档约定（D5-B）：不可验证，不选；
6. 共识卡自由文本（D6-B）：不可校验，不选；
7. 可选增强「推进结论附信心等级/残余风险」：用户明确不采纳。
