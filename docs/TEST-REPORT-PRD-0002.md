## 自审发现与修复（P4）

1. `scan_secrets` EMAIL 误报 `user@github.com`（占位示例 `git@github.com:user/my-app.git` 的第二段匹配）→ IGNORE_VALUE 增 `@github\.com`，`--history --strict` 复扫 PASS；
2. `smoke_init.py` 注入假 token 字面量被扫描器判为高危凭据 → 改为运行时拼接（源码不连续、注入文件仍可被拦截），复扫 PASS；
3. 冒烟默认作者名（默认用户名）触发个人信息 → 冒烟初始化显式 `--author smoke-user`（LICENSE 作者名属真实信息，扫描器人工复核语义正确）；
4. 模板 STATUS 骨架「重检行」须独立成行才匹配断言 → 骨架改独立行，断言通过。
