# archive — 项目归档区

> 模块：全通用。
> 用途：项目归档/退役时存放**归档说明与最终快照**（A 区，进 git，只读）。
> 本目录随模板初始化存在，未归档时保持为空（可删除说明文件以外的内容）。

## 何时使用

- 项目停止主动开发（弃用 / 迁移 / 长期冻结）且用户明确发起归档时，按根
  `AGENTS.md`「项目归档/退役」执行。

## 放什么

- `ARCHIVE.md`（本文件）：更新为归档说明——归档日期、原因、最终版本、迁移去向、
  如何重新激活；
- 最终快照/说明文档（如最终 README 副本、数据字典、迁移指引）；
- **不放**：发布产物（`dist/**` 随 Release 保留）、密钥/个人素材（走 `private/`
  与删除纪律）、可重建内容。

## 归档后状态

- 本目录内容只读维护；重新激活项目时先更新本文件与
  `private/AGENTS.md`「项目状态与版本」。
