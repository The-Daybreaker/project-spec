# MODULE.md — 收口（模块规范）

> **适用范围**：当 agent 负责本模块的产出——一期完成的收口动作时，加载并
> 遵循本文件。项目级总纲见仓库根 `AGENTS.md`。
> 
> 本模块依赖「审计」（放行后的产物）。
> 
> 本文件是「收口」模块自带的 agent 规范，随模块例化。

## 一、产物与落点

交付物落在 `workspace/delivery/`；变更日志写 `workspace/CHANGELOG.md`（给用户的版本日志，随发布）。发布动作项目自定。

## 二、运行过程

1. 写 CHANGELOG：把这期做了什么写进 `workspace/CHANGELOG.md`（给用户的版本日志）。
2. 确认收口方式：私有项目本地打 tag、本地安装即发布；公开项目上传 GitHub。
3. 不可逆动作动手前，把方案明说、征得用户同意。

## 三、规范

- 收口是项目自定义的：模板只留位子，具体怎么做每个项目自己定。
- 发布 / 推送是不可逆动作，动手前必须征得同意。

## 四、适用与边界

- **适用**：一期开发完成需要收口的项目。
- **不管**：开发、测试、审计、不更新用户版本号的小修改。
