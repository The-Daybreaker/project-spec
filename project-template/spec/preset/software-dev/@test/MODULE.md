# MODULE.md — 测试与验收（模块规范）

> **适用范围**：当 agent 负责本模块的产出——测试用例与测试报告时，加载
> 并遵循本文件。项目级总纲见仓库根 `AGENTS.md`。
> 
> 本模块依赖「开发执行」（产物）和「当期需求」（验收标准）。
> 
> 本文件是「测试与验收」模块自带的 agent 规范，随模块例化、随模块停用。

## 一、产物目录与例化

本模块的产物落在 `context/test/`，每期一份，编号递增：

```
context/test/
  TEST-0001.md   ← 测试用例 + 测试报告
  TEST-0002.md
```

每份包含：测试用例（测前整理）+ 测试结果（测后记录）。

启用时按 `assets/test-template.md`（仅参考格式）例化当期测试文档。

## 二、运行过程

1. 整理用例：开发完，根据 PRD 验收标准 + 接口契约，整理这一期的测试用例。
2. 按用例测：按测试用例跑，记录结果（过 / 不过 / 用户兜底）。
3. 用户兜底：agent 测不了的交给用户，实际体验一遍算真做完。
4. 归档：这期测完，测试文档原地归档（历史交给 git），下一期新开一份。

## 三、规范

- 小需求小修复免全套。
- 用例从 PRD 的验收标准来，不凭空造。

## 四、适用与边界

- **适用**：需要验证的产出。
- **不管**：审计、发布。
