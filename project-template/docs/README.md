# docs — 公开文档

本目录存放随仓库发布（公开）的项目文档。约定：

- 面向使用者/贡献者的文档放这里；**开发期文档**（设计、变更记录、测试报告）放
  `private/dev/`（不进 GitHub）。
- 每份文档在文件开头写明读者对象与维护者（负责随改动同步更新的人/角色）。
- 文档语言按项目约定（建议中文，双语项目按 README 约定同步）。
