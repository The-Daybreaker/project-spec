# RESEARCH — 调研记录（调研登记册）

> 模块：项目专用（B 区私有，不进 GitHub，由 private 子 git 管理）。
> 用途：承载红线 14「立项调研先行」的正式调研结果（调研问题、来源、候选对比、
> 结论）；可跨需求/决策复用，也是「创建前相似检查」（红线 7）的检索表。

## 使用规则（强制）

1. **触发**：红线 14 立项调研、技术选型、方案调研（M/L 档）；小调研可内嵌
   PRD/RFC 对应节，不建独立文档。
2. **追加更新（允许）**：发现记录**只追加**（每条带日期/来源，不改写不删除旧
   条目）；「结论与建议」为**当前有效结论**——新发现导致结论变化时直接覆盖
   （留痕靠发现记录时间线，必要时 CHANGELOG 一行）。
3. **重做调研**（主题/方向根本变化）：开新 `RESEARCH-XXXX` 取代（旧文档状态=
   已过期，仅状态元数据可改）。
4. **复用与防重复**：新调研前先查本目录索引（红线 7 相似检查）。
5. **引用**：PRD/RFC/ADR 只写 2-3 行摘要 + `详见 RESEARCH-XXXX`。

## 状态机

```
进行中 → 已完成（仍可追加新发现）→ 已过期（被新调研取代）
```

- 进行中→已完成 由 agent 完成调研后更新；→已过期 由新调研取代时标记。

## 编号

- `RESEARCH-0001` 起，4 位前缀零；文件名 `RESEARCH-0001-<topic>.md`；编号**永不重用**。
